## Agent Workflow

```text
Read requirements
    ↓
Inspect repository
    ↓
Plan
    ↓
Implement
    ↓
Test
    ↓
Security review
    ↓
Architecture review
    ↓
Update docs
    ↓
Update project state
```

## Important

Do not ask an AI coding agent to build the entire product in one step.

Work phase-by-phase and use the documentation as the project's source of truth.
